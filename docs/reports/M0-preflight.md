# M0 preflight report (sanitized summary)

Environment checks run before M1 on the development machine, then re-run at M1 kickoff and after a
kernel upgrade. Machine-specific detail (host names, user names, paths, accounts, disk sizes) is
omitted; `scripts/doctor.sh --redact` reproduces this report on any machine.

**Platform class:** x86-64 workstation · NVIDIA RTX 50-series, 16 GB · Windows with WSL2 ·
Ubuntu 24.04 · WSL kernel 5.15 at M0, 6.18 at the latest re-run.
